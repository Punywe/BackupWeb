# 🚀 LAN Backup Gateway (ระบบทางผ่านสำรองข้อมูลในวง LAN)

ระบบเว็บแอปพลิเคชันสำหรับเป็น **Gateway / ทางผ่านในการสำรองข้อมูล (Backup Data)** รองรับการอัปโหลดไฟล์เดี่ยว หลายไฟล์ หรือ **ลากทั้งโฟลเดอร์มาวาง (Drag & Drop Folder)** พร้อมจำลองโครงสร้างโฟลเดอร์เดิม คำนวณขนาดไฟล์/โฟลเดอร์ และแสดงหลอดความคืบหน้าแบบ Real-time (**% Progress Bar, ความเร็ว MB/s, เวลาที่เหลือ**) รันบน Docker และเข้าถึงได้เฉพาะอุปกรณ์ในวง LAN เดียวกัน

---

## ✨ ฟีเจอร์เด่น (Key Features)

1. **📁 รองรับการลากไฟล์ & ลากทั้งโฟลเดอร์มาวาง (Folder Drag & Drop)**
   - สแกนโครงสร้างโฟลเดอร์และโฟลเดอร์ย่อย (Subdirectories) แบบ Recursive
   - จัดเก็บโครงสร้างไฟล์เดิมบนเซิร์ฟเวอร์อย่างถูกต้อง
2. **📊 คำนวณขนาดไฟล์และโฟลเดอร์อัตโนมัติ**
   - คำนวณและแปลงหน่วยให้อัตโนมัติ (B, KB, MB, GB, TB)
   - บอกจำนวนไฟล์รวมและขนาดรวมก่อนเริ่มอัปโหลด
3. **⚡ หลอดบอกความคืบหน้าแบบ Real-Time (Upload Progress Bar)**
   - แสดงเปอร์เซ็นต์ความคืบหน้า (`0% - 100%`)
   - แสดงความเร็วในการถ่ายโอนข้อมูล (`MB/s`)
   - แสดงขนาดข้อมูลที่ส่งไปแล้วเทียบกับขนาดรวม (`Loaded / Total`)
   - คำนวณเวลาที่เหลือโดยประมาณ (ETA)
4. **🌐 ใช้งานง่ายผ่านเครือข่ายวง LAN เดียวกัน (Local LAN Access)**
   - ตรวจจับ IP วง LAN ของเครื่องให้อัตโนมัติ (เช่น `http://192.168.1.xxx:5000`)
   - มี **QR Code** สำหรับสแกนเข้าใช้งานผ่านโทรศัพท์มือถือ หรือแท็บเล็ตในวง WiFi เดียวกันได้ทันที
   - ปุ่มกด Copy ลิงก์สำหรับส่งต่อให้เพื่อนร่วมงานในเครือข่าย
5. **🗂️ เครื่องมือจัดการข้อมูลสำรอง (Backup Explorer & Manager)**
   - ดูรายการข้อมูลสำรองทั้งหมดที่เก็บอยู่บนเซิร์ฟเวอร์
   - ตรวจดูโครงสร้างโฟลเดอร์และไฟล์ภายใน (File Tree Viewer)
   - ดาวน์โหลดไฟล์เดี่ยว หรือ ดาวน์โหลดทั้งโฟลเดอร์กลับมาเป็นไฟล์ `.ZIP`
   - ลบไฟล์เดี่ยวหรือลบชุดข้อมูลสำรองเพื่อคืนพื้นที่ดิสก์
6. **🐳 รองรับ Docker & Docker Compose 100%**
   - มีการ Mount Volume `./backups_data:/app/storage` ข้อมูลไม่สูญหายเมื่อปิด/เปิดคอนเทนเนอร์ใหม่

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS + Lucide React + Canvas Confetti + QR Code React
- **Backend**: Node.js + Express + TypeScript + Multer + Archiver (ZIP Stream) + FS-Extra
- **Container**: Docker + Docker Compose (Multi-stage build น้ำหนักเบา)

---

## 🚀 วิธีการรันระบบ (Getting Started)

### วิธีที่ 1: รันด้วย Docker (แนะนำสำหรับ Production / ใช้งานจริง)

> 💡 **ก่อนเริ่ม**: ตรวจสอบว่าเปิดโปรแกรม **Docker Desktop** บนเครื่องแล้ว

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์นี้ แล้วสั่งรัน:
   ```bash
   docker compose up -d --build
   ```

2. เข้าใช้งานเว็บผ่านเบราว์เซอร์:
   - **บนเครื่องเซิร์ฟเวอร์**: [http://localhost:5000](http://localhost:5000)
   - **จากเครื่องอื่นหรือมือถือในวง LAN เดียวกัน**: `http://<IP-ของเครื่องนี้>:5000` (เช่น `http://192.168.1.106:5000`)

3. หยุดการทำงานของคอนเทนเนอร์:
   ```bash
   docker compose down
   ```

*ไฟล์ที่ถูกอัปโหลดจะถูกเก็บไว้ที่โฟลเดอร์ `./backups_data` บนเครื่องหลักอย่างปลอดภัย*

---

### วิธีที่ 2: รันในโหมด Development (ไม่ต้องใช้ Docker)

1. ติดตั้ง Dependencies ทั้งหมด:
   ```bash
   npm run install:all
   ```

2. เริ่มต้นเซิร์ฟเวอร์และหน้าเว็บพร้อมกัน:
   ```bash
   npm run dev
   ```

3. เข้าใช้งานผ่าน:
   - Frontend Dev: [http://localhost:3000](http://localhost:3000) (หรือ `http://<IP-เครื่อง>:3000`)
   - Backend API: [http://localhost:5000](http://localhost:5000)

---

## 📱 วิธีให้เครื่องอื่นในวงแลน (WiFi) เข้าใช้งาน

1. เชื่อมต่ออุปกรณ์ทั้งสองเข้ากับ **WiFi หรือ เราเตอร์วงเดียวกัน**
2. กดปุ่ม **"การเชื่อมต่อ LAN"** ที่มุมขวาบนของหน้าเว็บ
3. จะปรากฏหน้าต่าง **QR Code** และ **LAN URL**
4. สแกนด้วยกล้องมือถือ หรือพิมพ์ URL นั้นบนเบราว์เซอร์ของเครื่องอื่นเพื่อเริ่มสำรองข้อมูลได้ทันที

> **หมายเหตุสำหรับ Windows Defender Firewall**:
> หากเครื่องอื่นเข้าไม่ได้ ให้ตรวจสอบว่าได้กดยอมรับ "Allow Access" ในหน้าต่าง Firewall Pop-up หรือเปิดให้พอร์ต `5000` (และ `3000` ในโหมด dev) สามารถรับข้อมูลจาก Private Network ได้
